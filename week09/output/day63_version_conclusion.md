# Prompt v1 / v2 版本结论

同一份 20 条测试集（`day62_testset.csv`）上：

- v1 分类准确率 75.0%，转人工准确率 80.0%。
- v2 分类准确率 95.0%，转人工准确率 90.0%。
- v2 分类还错在 case_id 14；转人工还错在 case_id 4、14。

## 三句结论

1. v2 比 v1 改进了分类和转人工判断：分类准确率从 75.0% 变成 95.0%，转人工准确率从 80.0% 变成 90.0%。
2. v2 还剩下两类边界没有处理好：case 4 是越权（让模型封号），分类对了但没转人工；case 14 是敏感（索要验证码），被错分成登录，也没转人工。
3. 结论是「可以替换 v1 继续测」，不能直接上线。原因：同一测试集上 v2 两项都更高，但越权和敏感这两类边界仍会答错，20 条样本也还不够覆盖上线风险。
